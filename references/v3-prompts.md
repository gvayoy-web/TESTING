# Ejemplos de un único prompt

1. «Diseñador, crea una identidad completa para una cafetería: isotipo en SVG editable, paleta, tipografías, tarjeta, post e instrucciones de impresión. Planifica y genera los archivos que puedas en un solo turno.»
2. «Diseñador, haz una presentación de 10 diapositivas con diseño editorial, gráficos con fuentes y versión PDF; revisa tamaños de texto y cortes.»
3. «Diseñador, crea un producto 3D estilo arcilla y prepara GLB para mi web, render promocional y fallback móvil. Si no hay Blender, entrégame script reproducible y señala límites.»
4. «Diseñador, crea una campaña visual para una marca con portada, cuatro posts, dos stories y 15 segundos de motion, usando una identidad consistente. Ejecuta todo lo permitido con las herramientas conectadas.»
5. «Diseñador, rediseña y mejora mi repositorio web, construye las vistas y prueba su responsive, performance, accesibilidad y coherencia de marca. Conserva las rutas y datos existentes.»
