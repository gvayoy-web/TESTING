# Fuentes, atribución y obtención de originales

Diseñador es una integración original y contiene módulos propios, NO las versiones íntegras de los 9 proyectos de terceros. Algunos originales requieren scripts, ficheros de datos o binarios y no funcionarían pegando solo SKILL.md. Para instalarlos en un entorno con red, usa `scripts/install-originals.sh` o `scripts/install-originals.ps1`.

### Sobre licencias
Los originales poseen licencias distintas y algunas referencias declaran términos en LICENSE.txt; no se copian íntegramente aquí para evitar atribuir derechos inexactos. Revisa la licencia y seguridad del código de cada repositorio antes de copiarlo, ejecutar launchers, instalar npm o redistribuir. El catálogo de Bergside declara MIT; el paquete original propio de Diseñador se publica para uso privado.

### Entorno
- El plugin de ChatGPT no instala bibliotecas npm en tus webs ni incorpora automáticamente Three.js/GSAP a cada proyecto.
- El instalador de originales requiere Git, Node y npm/npx en un equipo local con internet.
- Las plantillas adaptadas dentro de Diseñador están disponibles sin ejecutar programas externos.
- Los links de `references/estilos-67.md` son referencias externas, no copias descargadas en el ZIP.
