# Preimpresión y diseño gráfico físico

1. Solicitar o localizar ficha técnica del impresor: tamaño de corte, tipo de papel, sangrado, perfil ICC, tintas especiales, resolución y PDF/X aceptado.
2. Hasta conocerla, trabajar con un master editable y una ficha de supuestos. No declarar un PDF de vista previa como arte final para imprenta.
3. Sangrado típico de 3 mm para ciertos productos, variable según impresor; zona segura interna independiente.
4. Resolución efectiva: se calcula después de escalar la imagen al tamaño final; 300 ppp es una referencia común para impresión de alta calidad, no regla universal.
5. RGB/sRGB para pantalla; CMYK y separaciones/proof únicamente con perfil y flujo conocidos. Evitar inferir equivalencias exactas HEX↔CMYK.
6. Comprobar sobreimpresión, trapping, tintas planas, negro enriquecido, transparencia, fuentes incrustadas/curvas y pliegues cuando aplique.
7. Exportar PDF/X con software real que lo soporte y verificar mediante preflight externo; si no, entrega PDF visual y lista de pasos pendientes.

## Checklist
[ ] dimensiones exactas [ ] bleed [ ] zona segura [ ] tipografía [ ] resolución [ ] perfiles y tintas [ ] mockup separado de troquel [ ] textos legales verificados [ ] revisión ortográfica.
