# Motion graphics y producción audiovisual

Fases: guión → beats → storyboard → animatic → composición y motion → audio/subtítulos → preview → QA → master.

## Timing
- Define FPS como entero/racional apropiado, no adivines timestamps de una canción sin escuchar o analizar el archivo disponible.
- Timing visual por beat con buffers para lectura; texto en pantalla suficiente según longitud, no meramente transiciones rápidas.
- Capas de composición para texto, UI, 3D, imágenes, partículas, audio y captions.
- Movimientos con easing y anticipación; evita cortes de palabras o cámara errática.
- Revisa primera y última escena, CTA completo, identificación de marca, número/contacto solo si provisto.

## Entrega
- Proyecto fuente editable en Remotion/Motion Canvas/Blender/editor real.
- Export MP4/WebM con resolución y fps revisados, más thumbnail/captions cuando se soliciten.
- Derechos musicales comprobados para uso comercial; nunca recomendar eludir licencias.
- No prometer un render si no se ejecutó en el turno.
