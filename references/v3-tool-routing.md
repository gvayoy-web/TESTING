# Herramientas y decisiones — sin suposiciones

## Por tarea
- Figma: componentes, variables, prototipos y handoff si la conexión existe y sus skills de uso fueron cargados.
- Canva: piezas gráficas, plantillas y materiales de marca solo si hay conector con permisos.
- Blender: modelado/renders/GLB si `blender` está instalado o existe herramienta 3D conectada.
- Three.js/R3F: experiencias 3D ejecutables en un proyecto web accesible con permisos.
- Python + SVG: vector maestro, fichas y artefactos reproducibles, usando generadores y validadores incluidos cuando resulte útil.
- Motion/Remotion/Motion Canvas: video si el runtime y render funcionan; si no, storyboard/proyecto fuente claro.
- Repositorios GitHub: lectura/edición mediante conector autorizado, no inventar checkout/deploy.
- PDF/PPTX/DOCX: emplear la capacidad especializada del host y sus instrucciones cuando se produzca ese tipo de archivo.
- ChatGPT no obtiene herramientas adicionales simplemente por mencionar un repo en este catálogo.

## Preferencias por coste
SVG para marcas y gráficas simples; raster para fotografía y pintura; CSS para motion de interfaz simple; WebGL/R3F solo donde realmente agrega valor; Blender en producción 3D completa; poster de respaldo en dispositivos con recursos limitados.
