# Diseñador v3 — Data Viz

**Activación:** Diseña dashboards, gráficos y narrativas de datos para web, presentaciones e impresión.

## Procedimiento
1. Valida datos, nulos, rangos, unidades, agregación y series temporales antes de elegir visual.
2. Selecciona gráfico correcto según comparación, tendencia, distribución, relación o composición.
3. Usa colores accesibles y etiquetas directas; reduce decoraciones y 3D que distorsionen el valor.
4. Documenta escala, filtros, interacción, estados vacíos y fuentes.
5. Prepara SVG estático para informes o código responsivo para web según petición.

## Entregable
Gráfico/código o especificación gráfica y tabla de procedencia de datos.

## Puerta de calidad
Fidelidad matemática, ejes honestos, unidades, tamaños y navegación accesible.

## Coordinación
Selecciona el soporte correcto, sigue el orquestador `designer-universal-autopilot` para tareas compuestas y aplica las reglas de atribución, edición autorizada y pruebas reales. Para detalles operativos consulta `references/v3-design-quality-gates.md` de la raíz del plugin. No afirmes haber ejecutado una herramienta ausente; entrega fuentes editables y resultados concretos cuando el entorno lo permita.
