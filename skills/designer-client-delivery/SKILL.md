# Diseñador v3 — Client Delivery

**Activación:** Cierra proyectos creativos con entregas profesionales, versiones y trazabilidad.

## Procedimiento
1. Construye nomenclatura consistente: cliente/proyecto/pieza/formato/versión.
2. Divide fuentes de exportaciones, previsualizaciones y entregables finales.
3. Adjunta README con formatos, enlaces, dimensiones, restricciones y licencias.
4. Entrega enlaces reales solo a rutas verificadas y manifiesta pruebas y supuestos.
5. Mantiene histórico y distingue estado borrador/aprobado/publicado; solicita autorización para publicación.

## Entregable
Paquete de fuentes y exports, manifest, README y checklist de validación.

## Puerta de calidad
Todos los enlaces y rutas existen, sin secretos o material sin licencia, archivos abren.

## Coordinación
Selecciona el soporte correcto, sigue el orquestador `designer-universal-autopilot` para tareas compuestas y aplica las reglas de atribución, edición autorizada y pruebas reales. Para detalles operativos consulta `references/v3-artifact-contracts.md` de la raíz del plugin. No afirmes haber ejecutado una herramienta ausente; entrega fuentes editables y resultados concretos cuando el entorno lo permita.
