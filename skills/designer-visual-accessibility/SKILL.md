# Diseñador v3 — Visual Accessibility

**Activación:** Diseña piezas gráficas, datos, interfaces y video accesibles sin comprometer su lenguaje visual.

## Procedimiento
1. Evalúa contraste, tamaños, jerarquía, lectura lineal y contexto cultural.
2. No uses solo color para estado o valor de un gráfico; añade labels/patterns.
3. Para motion aplica reduced-motion y evita flashes o movimientos innecesarios.
4. Para video ofrece subtítulos, para imágenes alt-text funcional, para presentaciones lectura estructurada.
5. Prueba escala, zoom, pantallas pequeñas y legibilidad impresa.

## Entregable
Revisión de accesibilidad con medidas y alternativas por soporte.

## Puerta de calidad
Auditoría basada en criterios actuales verificables; no afirmar conformidad sin pruebas.

## Coordinación
Selecciona el soporte correcto, sigue el orquestador `designer-universal-autopilot` para tareas compuestas y aplica las reglas de atribución, edición autorizada y pruebas reales. Para detalles operativos consulta `references/v3-design-quality-gates.md` de la raíz del plugin. No afirmes haber ejecutado una herramienta ausente; entrega fuentes editables y resultados concretos cuando el entorno lo permita.
