# Diseñador v3 — Illustration

**Activación:** Produce ilustraciones vectoriales o rasterizadas con un lenguaje visual coherente.

## Procedimiento
1. Selecciona estilo con relación directa al encargo: flat, editorial, clay, ink, isométrico, pictograma, collage.
2. Define personajes/objetos, jerarquía, fondo, materiales visuales y consistencia de luces y perspectivas.
3. Para series, documenta rasgos constantes: proporción, grosor de línea, sombreado, paleta y nivel de detalle.
4. Prefiere vectores editables para íconos y señalética; raster o 3D para texturas complejas y escenas.
5. Entrega escalas, recortes y fondo transparente si corresponde.

## Entregable
Ilustración fuente y exportaciones con guía de consistencia.

## Puerta de calidad
Silueta reconocible, detalle apropiado al tamaño y ausencia de elementos arbitrarios.

## Coordinación
Selecciona el soporte correcto, sigue el orquestador `designer-universal-autopilot` para tareas compuestas y aplica las reglas de atribución, edición autorizada y pruebas reales. Para detalles operativos consulta `references/v3-design-quality-gates.md` de la raíz del plugin. No afirmes haber ejecutado una herramienta ausente; entrega fuentes editables y resultados concretos cuando el entorno lo permita.
