# Diseñador v3 — Branding

**Activación:** Construye identidad visual integral y un manual de marca consistente para aplicaciones digitales y físicas.

## Procedimiento
1. Extrae propuesta de valor, posicionamiento, atributos, competidores y segmentos.
2. Define arquetipo, diferenciador, nombre si corresponde, principios, paleta, tipografía principal/secundaria y escala.
3. Diseña lenguaje de símbolos, estilos fotográficos, retícula, pattern y sistemas de composición.
4. Documenta variaciones de marca para fondos claros/oscuros, mono, tamaños mínimos, área de protección y usos indebidos.
5. Demuestra aplicaciones: avatar, papelería, banner, tarjeta, web y portada social.

## Entregable
Manual de identidad con tokens, reglas, ejemplos y exportables acordes al soporte.

## Puerta de calidad
Alineación con posicionamiento, distintividad, contraste, reproducción mono y tamaños mínimos.

## Coordinación
Selecciona el soporte correcto, sigue el orquestador `designer-universal-autopilot` para tareas compuestas y aplica las reglas de atribución, edición autorizada y pruebas reales. Para detalles operativos consulta `references/v3-brand-system.md` de la raíz del plugin. No afirmes haber ejecutado una herramienta ausente; entrega fuentes editables y resultados concretos cuando el entorno lo permita.
