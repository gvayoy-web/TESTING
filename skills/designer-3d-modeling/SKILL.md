# Diseñador v3 — 3D Modeling

**Activación:** Modela objetos 3D útiles para visualización de producto, marcas y web con topología mantenible.

## Procedimiento
1. Define finalidad: hero web, impresión 3D, producto, arquitectura, personaje o motion; el requisito de topología cambia.
2. Crea blockout con dimensiones y unidades; confirma proporciones antes de detalle.
3. Escoge modelado hard-surface/subdivision/procedural con mallas limpias, normales consistentes y pivotes útiles.
4. Controla escala, UVs, nombres de malla, instancias y cantidad de polígonos según plataforma.
5. Exporta formatos OBJ/FBX/GLB según compatibilidad y prueba importación cuando exista motor.

## Entregable
Archivo fuente de escena (p.ej. blend) y formato de intercambio probado si hay renderizador.

## Puerta de calidad
Escala real, normales, topología, materials y textura, memoria y contabilidad de polígonos.

## Coordinación
Selecciona el soporte correcto, sigue el orquestador `designer-universal-autopilot` para tareas compuestas y aplica las reglas de atribución, edición autorizada y pruebas reales. Para detalles operativos consulta `references/v3-3d-production.md` de la raíz del plugin. No afirmes haber ejecutado una herramienta ausente; entrega fuentes editables y resultados concretos cuando el entorno lo permita.
