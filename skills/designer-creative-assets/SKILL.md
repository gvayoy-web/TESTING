# Diseñador v3 — Creative Assets

**Activación:** Planifica y prepara recursos visuales para proyectos: imágenes, vectores, audio y modelos.

## Procedimiento
1. Inventaría assets disponibles y anota licencia/procedencia, usos y resoluciones.
2. Escoge formato según cometido: SVG para símbolo, PNG/WebP/AVIF para web, TIFF/PDF para imprenta, GLB para 3D.
3. Calcula variantes y recortes evitando exportación de duplicados innecesarios.
4. No inventes URLs a recursos ni trates un mockup como fotografía factual.
5. Documenta alt-text, nombre semántico y versiones para revisión.

## Entregable
Manifest de recursos con formatos, licencias, variantes y tamaños.

## Puerta de calidad
Integridad, nombres reproducibles, permisos, calidad y peso de archivo.

## Coordinación
Selecciona el soporte correcto, sigue el orquestador `designer-universal-autopilot` para tareas compuestas y aplica las reglas de atribución, edición autorizada y pruebas reales. Para detalles operativos consulta `references/v3-artifact-contracts.md` de la raíz del plugin. No afirmes haber ejecutado una herramienta ausente; entrega fuentes editables y resultados concretos cuando el entorno lo permita.
