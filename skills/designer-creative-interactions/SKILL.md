# Interacciones con causa y efecto

- Define la acción del usuario, el cambio de estado y el feedback perceptible; no animar sin decisión de producto.
- Para desktop usa hover enriquecido, pero conserva foco y activación equivalente por teclado/touch.
- Evita scroll-jacking y navegación paralela que quite control al visitante.
- Una interacción espacial debe volver a estado inicial y tolerar interrupción y rutas atrás/adelante.
- En componentes de contenido: micro feedback CSS; en hero inmersivo: coreografía localizada; en aplicación operativa: estados breves y predecibles.
- Si se crea UI accesible, no ocultar controles dentro de una escena WebGL sin alternativa DOM.
