# Style Lab — inteligencia estética

Si hay imagen/referencia concreta, usa primero `designer-visual-mind` para extraer evidencias; carga el catálogo completo de estilos solo cuando resulte indispensable.

1. Construye una descripción concreta del producto, industria, audiencia, nivel de energía y modo de uso.
2. Selecciona **1 estilo base, hasta 1 secundario, hasta 1 acento** del inventario `references/estilos-67.md`. Usa la matriz `references/combinaciones-v2.md` para combinaciones conscientes. No uses estilos de moda sin conexión con la identidad.
3. Define: metáfora visual, tipografía dominante + complementaria, ritmo de módulos, escala espacial, sistema de color, tratamiento de imágenes, transiciones y gesto insignia.
4. Diseña 3 superficies: hero, módulo de beneficio y CTA final. Comprueba que todo pertenece a la misma familia. Una misma retícula puede alternar composición pero no perder coherencia.
5. Elige clay para interfaces táctiles y amistosas; glass para capas sobre fondos ricos; brutalismo para marcas de voz fuerte; editorial para autoridad y lectura; 3D para productos espaciales; skeuomorphism solo si la materialidad comunica uso.
6. Traduce la estética a tokens y componentes. Evita copiar pantallas o marcas existentes; referencias sirven para análisis, no reproducción literal.
7. Prueba claridad con texto real: titular, evidencia, etiqueta, CTA. Hero legible en 5 segundos, contrastes consistentes y 375px usable.

Entregable: concepto de una frase, tokens, distribución de secciones, comportamiento interactivo y justificación de costo/beneficio del motion.
