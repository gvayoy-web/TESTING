# Diseñador v3 — Visual Storytelling Advanced

**Activación:** Desarrolla narrativas visuales consistentes para campañas transmedia y experiencias inmersivas.

## Procedimiento
1. Plantea conflicto, promesa y punto de transformación, con una imagen memorable.
2. Mapea beats a formatos: portada, secuencia, landing, reels, render, producto.
3. Selecciona uno o dos motivos visuales recurrentes y varía escala, no replica layouts.
4. Alinea ritmo de scroll/motion con los cambios de información, no con transiciones arbitrarias.
5. Crea versiones con narrativa entendible sin animación.

## Entregable
Arco narrativo visual y sistema de aplicaciones entre medios.

## Puerta de calidad
Mismo mensaje, suficiente contraste, CTA en momento correcto y coherencia visual.

## Coordinación
Selecciona el soporte correcto, sigue el orquestador `designer-universal-autopilot` para tareas compuestas y aplica las reglas de atribución, edición autorizada y pruebas reales. Para detalles operativos consulta `references/v3-studio-operating-system.md` de la raíz del plugin. No afirmes haber ejecutado una herramienta ausente; entrega fuentes editables y resultados concretos cuando el entorno lo permita.
