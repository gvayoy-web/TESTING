# SEO para experiencias web creativas

- Prioriza HTML semántico, texto indexable, títulos concretos, metadata real, og:image válida, canonicals cuando sea apropiado y enlaces rastreables.
- Evita heroes compuestos solo por canvas/imagen que desaparecen sin JS. Los CTA y contenidos primarios deben vivir fuera de WebGL.
- Asegura rutas correctas, respuesta HTTP apropiada, enlaces internos, sitemap/robots si el framework ya lo implementa.
- Optimiza Core Web Vitals y carga de imágenes; no manipules lazy loading de elemento LCP por estética.
- Aplica structured data únicamente cuando coincida con datos reales, sin reseñas/testimonios fabricados.
- En SSR/SPA, comprueba render previo a hidratación y que la navegación sigue funcionando.

Entrega checklist de indexabilidad y errores corregidos.
