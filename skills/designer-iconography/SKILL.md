# Diseñador v3 — Iconography

**Activación:** Diseña familias de iconos originales, consistentes y exportables en SVG.

## Procedimiento
1. Define grid 24/32, stroke, caps, uniones, radios y márgenes ópticos.
2. Establece gramática visual y metáforas comprensibles antes de diseñar cada icono.
3. Crea iconos con formas limpias y prueba a tamaños reales; evita confundir icono de marca con decorativo.
4. Organiza nombres, stroke y variantes solid/outline y condiciones de accesibilidad.
5. Exporta SVG y sprite solo cuando los requisitos técnicos lo justifiquen.

## Entregable
Colección de iconos SVG con sistema de construcción y nomenclatura.

## Puerta de calidad
Identificación correcta, consistencia óptica, tamaño táctil y contraste.

## Coordinación
Selecciona el soporte correcto, sigue el orquestador `designer-universal-autopilot` para tareas compuestas y aplica las reglas de atribución, edición autorizada y pruebas reales. Para detalles operativos consulta `references/v3-vector-guide.md` de la raíz del plugin. No afirmes haber ejecutado una herramienta ausente; entrega fuentes editables y resultados concretos cuando el entorno lo permita.
