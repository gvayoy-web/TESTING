# Diseñador v3 — Typography Pro

**Activación:** Define jerarquías tipográficas, composiciones editoriales y licencias de fuentes.

## Procedimiento
1. Construye escala modular y tokens de display, h1-h6, párrafo, caption y microcopy.
2. Elige familias por carácter, idioma, legibilidad, diacríticos y licencia; confirma pesos disponibles.
3. Ajusta tracking, kerning, line-height, columnas, widows/orphans, numerales y estructura responsive.
4. Para marca, define usos restringidos, fallback tipográfico y criterios de incrustación en PDF.
5. Comprueba pruebas impresas y pantallas pequeñas en idioma final.

## Entregable
Escala tipográfica, specimens, CSS tokens o estilos editoriales y reglas de uso.

## Puerta de calidad
Acentos correctos, licencia verificable, contrastes, ritmo vertical y jerarquía clara.

## Coordinación
Selecciona el soporte correcto, sigue el orquestador `designer-universal-autopilot` para tareas compuestas y aplica las reglas de atribución, edición autorizada y pruebas reales. Para detalles operativos consulta `references/v3-brand-system.md` de la raíz del plugin. No afirmes haber ejecutado una herramienta ausente; entrega fuentes editables y resultados concretos cuando el entorno lo permita.
